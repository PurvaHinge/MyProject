# MyProject
Features
1)Displays book issue and return data using graphs

2)Provides 8 different data visualizations for analysis

3)Shows daily book circulation trends

4)Tracks new member registrations

5)Displays total books available in the library

6)Visualizes fine collection over time

7)Shows number of active library members

8)Tracks damaged or lost books

9)Uses CSV file for storing library data

10)Implemented using Python, Pandas, and Matplotlib

11)Easy to run and understand for beginners

12)Project is uploaded and managed on GitHub
